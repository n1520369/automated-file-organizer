# Automated File Organizer

## Overview

A Python automation tool that organizes files into categorized folders automatically based on file extensions.

## Features

- Automatic file sorting
- Creates folders dynamically
- Supports Images, Documents, Videos and Archives
- Handles unknown file types
- Improves file management

## Technologies Used

- Python
- OS Module
- shutil Module
